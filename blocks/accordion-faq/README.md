# accordion-faq

Custom **accordion** block. Purpose: faq.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per question (7 on the source page), 2 cells: cell 1 = question text (plain text); cell 2 = answer (one or more paragraphs, lists, links, inline bold). Empty rows are skipped, a missing answer cell gives an empty answer, and empty headings or empty trailing elements in answers are removed. Extra cells are added to the answer.

## Supported variations

No variations.
